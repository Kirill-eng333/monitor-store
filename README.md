🛒 Simple E-commerce Website (Educational Project)
Учебный проект интернет-магазина, созданный для отработки базовых навыков фронтенд-разработки. Проект включает в себя каталог товаров, систему авторизации и рабочую корзину. Все данные сохраняются локально в браузере пользователя. 💻✨

🛠 Что реализовано в проекте:
📦 Каталог товаров: Главная страница с наглядными карточками, ценами и изображениями товаров.

🔐 Авторизация: Полноценные формы для регистрации и входа в систему. Логика проверки данных написана на чистом JavaScript.

🛍 Корзина: Функционал добавления товаров, удаления позиций и автоматического расчета итоговой стоимости.

⭐ Рейтинги: Интерактивная система оценки товаров «звездами» с сохранением вашего выбора.

💾 LocalStorage: Приложение «запоминает» пользователей и содержимое корзины даже после закрытия вкладки или перезагрузки.

🏗 Технологии:
🌐 HTML5: Семантическая структура страниц и удобные формы.

🎨 CSS3: Стилизация интерфейса с использованием градиентов, Flexbox и адаптивности.

⚡ JavaScript (Vanilla JS): Вся логика магазина реализована без сторонних библиотек, только чистый код.
